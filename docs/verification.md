# 최초 시험 배포·검증 기록

이 문서는 최초 `to2027os` 시험 배포 당시의 기록입니다. 이후 저장소·프로덕션 이름은 `os26to27`, 영문 학교 표기는 `ohsung`으로 정리했습니다. 현재 구성과 자동 배포 검증은 [프로덕션 기록](production.md)을 확인하세요.

검증일: 2026-10-27 (한국 시간)

## 배포 환경

- 시험 주소: https://to2027os.pages.dev
- 최종 성공 배포 ID: `b46eed13-49a2-4e84-b5d4-e87d2d5dac4c`
- Cloudflare Pages Functions + D1 `osung-letters` (APAC)
- D1 ID: `416e12bb-7970-43df-84f7-fd0e0556e1f8`
- 요청 제한: 공개 URL이 비활성인 `osung-rate-limiter` 서비스 Worker
- 현재 운영 단계: A. 타자 문구: 임시 애국가 1절·후렴, 연습 기록으로 구분
- 공개 데이터: 승인된 실제 학생 글 없음, 빈 정적 JSON 배포
- GitHub 원격 저장소는 설정되어 있으며, 이번 작업에서 커밋·푸시하지 않음

CLI의 만료된 OAuth를 대신해 연결된 Cloudflare 도구로 리소스·바인딩을 구성하고, 단기 Pages 업로드 JWT를 메모리와 stdin으로만 전달하여 배포했습니다. 일반 재배포는 README의 Wrangler 절차를 사용합니다.

## 브라우저 검증

Chromium 기반 인앱 브라우저에서 수행했습니다.

1. 로컬 글 작성 → D1 저장 201 → 완료 화면 및 접수번호 확인.
2. 관리자 UI 로그인 → 목록 조회 → 공개용 본문 편집·승인·순서 저장. 원문 표시 유지.
3. 애국가 문구를 키보드 입력 경로로 완성 → 0오타 결과 → IndexedDB 저장 성공 → 기록 화면에서 1위·점수·시간 일치.
4. 붙여넣기 시 입력 차단 안내 확인.
5. 미완료 타자 중 다른 경로 이동 시 경고 확인. 이탈 후 완료 기록 건수가 증가하지 않음.
6. 네트워크를 오프라인으로 전환하여 글 제출 실패 유도. 작성 내용 유지·동일 요청 재시도 UI 확인. 네트워크 복구 후 완료 화면 도달.
7. Functions나 DB가 없는 별도 정적 서버에서 승인된 예제 JSON의 `/welcome` 정상 열람. 한글·줄바꿈 표시 확인.
8. 390px 모바일 뷰포트에서 공개 페이지와 배포된 작성 페이지의 가로 넘침 없음 확인. 확인 후 뷰포트·네트워크 설정 복원.
9. 배포된 `/welcome`에는 예제 데이터가 포함되지 않고 준비 중 화면이 표시됨을 확인.

화면 증빙은 Git에서 제외된 `artifacts/site-preview.png`, `artifacts/welcome-mobile.png`에 있습니다. 모바일 공개 페이지 증빙은 **로컬 예제 데이터**입니다.

## 실제 원격 환경 검증

`scripts/smoke.mjs`로 HTTPS 배포 서버에서 아래 흐름을 완료했습니다.

- 비인증 관리자 요청 401
- 실제 관리자 로그인과 쿠키 발급
- D1 접수 201, 동일 키 재전송 200과 동일 접수번호
- 승인·공개용 편집, 원문 보존
- 공개 JSON·전체 JSON·CSV 내보내기
- 공개 제외로 변경 후 공개 JSON에서 사라짐
- 로그아웃 응답

검증에 사용한 원격 시험 레코드 1건은 ID·접수 키·검증 별명이 모두 일치하는 조건으로 정리했습니다. 정리 후 원격 글 건수는 0건입니다. 결과 요약은 `artifacts/smoke-result.json`에 보관합니다.

## 남은 현장 검증·운영 결정

- 실제 운영 PC의 Chrome·Edge·Safari에서 물리 키보드 한글 두벌식 IME 확인. 인앱 브라우저는 CDP IME 조합 명령을 지원하지 않아 실제 IME 검증을 대신하지 못합니다.
- 실제 PC에서 창 포커스 이탈·새로고침·브라우저 강제 종료·저장 공간 부족 시나리오 확인.
- 최종 도메인과 입학식 날짜 확정, 인쇄한 QR을 실제 스마트폰으로 스캔. 생성된 QR은 현재 시험 주소용입니다.
- 공식 대회 문구·참가 횟수·상품 기준 확정 후 새 challengeId로 전환.
- 실제 운영 전 관리자 임시 비밀번호 변경, 글 길이·별명·보유 및 공개 종료 정책 확정.
- 행사 당일 운영 기기 기록 내보내기와 별도 저장 위치 백업, 실제 운영 DB의 복구 훈련.

Stage 7의 시각 디자인 개선은 진행하지 않았습니다. 기본 반응형 CSS만 적용했습니다.
